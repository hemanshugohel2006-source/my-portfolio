# Hemanshu Gohel — Portfolio

Modern, high-performance developer portfolio and interactive software showcase built with React 19, Tailwind CSS v4, Framer Motion, and Vite.

## Highlights

- **Dynamic Boot Splash Screen**: Animated boot logs, progress loading bar, and skip control.
- **Hero & Telemetry**: Dynamic TypeScript code inspector, performance metrics, and quick action coordinates.
- **Interactive Developer CLI**: In-browser terminal supporting commands like `help`, `about`, `skills`, `projects`, `contact`, `cat resume`, and `sudo hire`.
- **Project Case Studies**: Categorized software projects with detailed architecture modal, highlights, and direct repository links.
- **Competency Matrix**: Interactive tech stack browser with live search and proficiency meters.
- **Direct Contact Dispatch**: Interactive contact form with input validation, copy-to-clipboard email integration, and celebratory feedback.
- **Interactive Resume Modal**: In-browser formatted resume with printable view.

## Development

```bash
npm install
npm run dev
```

Server will start on `http://localhost:3000`.

## Production Build

```bash
npm run build
```
